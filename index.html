Novedades de la versión v1.2.10

Observabilidad & Sincronización

  • Captación automática de variable del ERP con DSN de Sentry.
  • Los errores originales de sincronización se conservan para facilitar su diagnóstico.

Bugfixes & Validación

  • Corrección de error TypeError en geometrías tras split.
  • Corrige nodos colgantes y violación de unicidad.
  • Refactorización en la detección de herramientas.

Rendimiento & UX

  • Eliminación de llamadas redundantes a DB.
  • Control mejorado de formularios abiertos.
  • Actualización a Koo (v6.6.4) y Sentry-sdk (v2.57.0).

Instalación vía Terminal

Para instalar QGIS y las dependencias, ejecuta:

sudo apt update && sudo apt install qgis qgis-plugin-grass -y

Luego, en QGIS, ve a Complementos > Administrar e instalar > Instalar a partir de un archivo ZIP y selecciona el archivo descargado.
