Guía de instalación rápida de QGIS
  1. Ejecutar: Haz doble clic sobre el archivo instalador .msi que has descargado.
  2. Aceptar términos: Haz clic en Next, marca la casilla para aceptar los términos de licencia y vuelve a pulsar Next.
  3. Instalar: Pulsa el botón Install. (Si Windows te pide permisos de administrador, haz clic en "Sí").
  4. Finalizar: Espera a que se complete la barra de progreso y haz clic en Finish. ¡QGIS ya está listo para usarse!

Guía de Instalación del QGisce Plugin
  1. Limpieza previa (en caso de tener una versión anterior): Desinstale el plugin actual desde el gestor. Elimine la carpeta qgisce en la ruta %APPDATA%\QGIS\QGIS3\profiles\default\python\plugins\ si existe.
  2. Despliegue: Ejecute el archivo .exe descargado y siga las instrucciones.
  3. Activación: Reinicie QGIS. Diríjase a Complementos > Administrar e instalar complementos y verifique que QGisce esté marcado como activo.

Guía de instalación rápida de QGIS

Sigue estos sencillos pasos para instalar la última versión de QGIS. Solo tendrás que copiar los comandos que están en los recuadros y pegarlos en tu sistema.

Paso 1: Abrir la terminal — Presiona las teclas Ctrl + Alt + T al mismo tiempo en tu teclado. Se abrirá una ventana negra.

Paso 2: Instalar herramientas necesarias — Copia el siguiente texto, pégalo en la terminal y presiona Enter. (Es posible que te pida tu contraseña de usuario; al escribirla no se verán asteriscos, es normal. Escríbela y presiona Enter).

sudo apt update && sudo apt install gnupg software-properties-common wget -y

Paso 3: Añadir la clave de seguridad de QGIS — Copia y pega estas dos líneas, una por una, presionando Enter después de cada una:

sudo mkdir -m755 -p /etc/apt/keyrings
sudo wget -O /etc/apt/keyrings/qgis-archive-keyring.gpg https://download.qgis.org/downloads/qgis-archive-keyring.gpg

Paso 4: Conectar con el servidor oficial — Copia todo este bloque de texto de una sola vez, pégalo en la terminal y presiona Enter. Esto configurará tu equipo automáticamente:

cat <<EOF | sudo tee /etc/apt/sources.list.d/qgis.sources Types: deb deb-src URIs: https://qgis.org/ubuntu Suites: $(lsb_release -cs) Architectures: amd64 Components: main Signed-By: /etc/apt/keyrings/qgis-archive-keyring.gpg EOF

Paso 5: Instalar el programa — Por último, dile a tu equipo que descargue e instale QGIS copiando y pegando este comando:

sudo apt update && sudo apt install qgis qgis-plugin-grass -y

¡Listo! Dependiendo de tu conexión a internet, este último paso puede tardar un par de minutos. Cuando termine y vuelva a aparecer tu nombre de usuario en la terminal, ya podrás cerrar la ventana, buscar QGIS en tu menú de aplicaciones y abrirlo.

Guía de Instalación del QGisce Plugin vía (.zip)

Paso 1: Preparar el archivo

  1. Asegúrate de tener el archivo descargado en tu ordenador (por ejemplo, qgisce_plugin_v1.2.2.zip).
  2. No extraigas el contenido del archivo ZIP. QGIS se encargará de instalarlo directamente desde el paquete comprimido.

Paso 2: Acceder al Gestor de Complementos

  1. Abre QGIS en tu sistema.
  2. En la barra de menú superior, haz clic en Complementos (Plugins).
  3. Selecciona la opción Administrar e instalar complementos... (Manage and Install Plugins...). (Esto abrirá una nueva ventana con el repositorio de QGIS).

Paso 3: Instalar desde ZIP

  1. En la ventana del Gestor de Complementos, fíjate en el menú lateral izquierdo y selecciona la pestaña Instalar a partir de un archivo ZIP (Install from ZIP).
  2. Haz clic en el botón de los tres puntos [...] junto al campo "Archivo ZIP".
  3. Navega por las carpetas de tu ordenador y selecciona el archivo .zip que descargaste en el Paso 1.
  4. (Opcional) Si estás actualizando una versión anterior, asegúrate de marcar la casilla "Reemplazar si ya existe una versión más antigua".
  5. Finalmente, haz clic en el botón Instalar complemento (Install plugin).

Paso 4: Verificación

  1. Una vez que la barra de progreso termine, deberías ver un mensaje de éxito en la parte superior de la ventana.
  2. Cierra la ventana del gestor.
  3. El plugin QGisce ya está instalado y debería estar visible en tu interfaz (revisa las barras de herramientas o el menú superior).
